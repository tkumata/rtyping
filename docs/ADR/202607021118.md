# ADR: 描画バッファテストと状態遷移テストを追加する

## Status

Accepted

## Context

既存テストはドメイン、ユースケース、設定保存、入力ハンドラの単体確認が中心である。TUI は描画ヘルパーの一部を確認しているが、画面全体を `ratatui` の描画バッファとして確認するテストは少ない。

Menu、Loading、Stats はユーザー導線の入口と復帰点であり、表示文言や状態遷移が壊れると操作不能に近い退行になる。

## Decision

- Menu、Loading、Stats の描画は `ratatui::backend::TestBackend` と `Terminal` で描画し、バッファ文字列から主要文言を確認する。
- 状態遷移テストは既存の入力ハンドラに追加し、Help 表示中の入力隔離と Stats からの復帰を固定する。
- 実装ロジックは変更せず、テスト専用ヘルパーのみを追加する。
- テスト追加後に `make check` と `make build` を実行する。

## Consequences

- UI の見た目全体を厳密なスナップショットにはしないため、軽微なレイアウト変更への追従コストを抑えられる。
- 主要文言と状態遷移は回帰検出できるが、色や座標の詳細確認は既存の小さな描画ヘルパーテストに委ねる。
