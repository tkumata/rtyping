# ADR: Stats 画面を成績ダッシュボードとして表示する

## Status

Accepted

## Context

現在の Stats 画面は保存済み履歴の統計を中央寄せのテキスト一覧として表示している。
この表示では、自己ベスト、平均、直近推移、頻出ミス文字の優先順位が弱く、ユーザーが現在地と改善点を読み取りにくい。

一方で、履歴保存形式と `HistoryStats` の集計定義は Result 画面とも共有されており、今回の変更で集計軸を増やすと影響範囲が広がる。

## Decision

Stats 画面は `HistoryStats` の既存フィールドだけを使い、成績ダッシュボードとして描画する。

- Best WPM、Avg WPM、Avg Accuracy、Runs を上段 KPI として表示する。
- 直近10回 WPM は数値列とミニグラフで表示する。
- 頻出ミス文字は横棒グラフで表示する。
- 履歴がない場合は Timed セッション完了を促す空状態メッセージを表示する。

履歴保存形式、集計定義、Stats 画面の入力処理、Result 画面の履歴サマリ表示は変更しない。

## Consequences

- Stats 画面で成績の現在地と改善対象を把握しやすくなる。
- 表示改善は描画層に閉じるため、履歴保存や Result 画面への影響を避けられる。
- 将来、期間別統計や成長差分を追加する場合は、`HistoryStats` の集計定義と Result / Stats の表示契約を同時に見直す必要がある。
